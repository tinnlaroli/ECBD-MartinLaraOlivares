### Descripción 

Repositorio con prácticas y ejercicios realizados en **Jupyter Notebook** para la asignatura de Extracción de Conocimiento en Base de Datos.  
Proyecto elaborado como parte del curso **Bases de Datos** de la carrera **Ingeniería en Desarrollo de Software**.

---

### Contenido 

- Prácticas de Anaconda y Jupyter Notebook
- Ejercicios de extracción, transformación y análisis de datos
- Documentación detallada de cada práctica

---

##  Uso

1. Clona el repositorio:
    ```sh
    git clone https://github.com/tinnlaroli/ECBD-MartinLaraOlivares.git
    ```
2. Abre los archivos `.ipynb` en **Jupyter Notebook** o **JupyterLab**.
3. Instala/activa el entorno de Anaconda con las librerías necesarias si hace falta.
